# Процесс публикации релизов GovPro AI

Публичный репозиторий релизов отделён от инженерного репозитория проекта.

## Перед публикацией

Для каждой версии необходимо проверить:

1. номер версии;
2. целевой канал — Stable или Beta;
3. платформы и архитектуры;
4. состав установочных файлов;
5. SHA-256 каждого публикуемого артефакта;
6. цифровую подпись, если она используется;
7. содержимое release notes;
8. совместимость версии клиента с серверной частью;
9. отсутствие секретов и приватных данных в артефактах.

## Формат заметок

Рекомендуемый порядок:

- **Новое**
- **Улучшено**
- **Исправлено**
- **Безопасность**
- **Известные ограничения**
- **Установка**
- **Контрольные суммы**

## Важное правило

Не публикуйте неподписанные или непроверенные установщики как Stable.

GitHub Releases используется как пользовательская витрина и хранилище артефактов. Клиент GovPro AI в дальнейшем должен получать машиночитаемые метаданные обновления, а не разбирать HTML страницы GitHub.

## История

История выпусков должна оставаться доступной через GitHub Releases, чтобы пользователь мог определить, какая версия была опубликована и какие изменения она содержала.
