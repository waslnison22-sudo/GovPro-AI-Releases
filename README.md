# GovPro AI

**Официальный публичный репозиторий релизов GovPro AI.**

GovPro AI — настольное приложение для работы с правилами, регламентами, нормативной информацией, доказательствами и делами с использованием ИИ.

## Что здесь публикуется

Этот репозиторий предназначен для пользователей GovPro AI. Здесь размещаются:

- официальные версии приложения;
- установочные файлы для поддерживаемых платформ;
- заметки к релизам;
- контрольные суммы SHA-256;
- сведения о цифровой подписи и целостности файлов;
- история предыдущих выпусков.

Исходный инженерный код проекта хранится отдельно и не является частью этого репозитория.

## Официальные релизы

Все стабильные версии публикуются через GitHub Releases:

**[Открыть все релизы](../../releases)**

Пока опубликованных production-релизов нет. Текущий pipeline готовит и проверяет официальные Beta-сборки; публикация Stable намеренно заблокирована до подключения и проверки подписи релизов.

Каждый релиз содержит версию, дату публикации, список изменений и доступные файлы для установки.

## Каналы

### Stable

Стабильные версии, предназначенные для обычного использования.

### Beta

Предварительные версии для проверки новых возможностей. Beta-релиз может содержать незавершённые изменения и не должен рассматриваться как эквивалент Stable.

## Установка

1. Откройте страницу [Releases](../../releases).
2. Выберите нужную версию.
3. Скачайте установщик для своей платформы.
4. Перед установкой при необходимости проверьте SHA-256 и сведения о подписи файла.
5. Установите приложение и запустите GovPro AI.

## Безопасность

Для официального релиза важно проверять:

- источник загрузки;
- номер версии;
- целостность скачанного файла;
- цифровую подпись, если она указана для конкретного артефакта.

Не скачивайте установщики GovPro AI из неизвестных зеркал или сторонних файловых архивов.

Если вы обнаружили уязвимость, не публикуйте эксплуатационные детали в открытом Issue. Используйте предусмотренный приватный канал раскрытия уязвимостей проекта.

## Версии приложения и базы знаний

Версия приложения и версия базы знаний — разные сущности.

Релиз приложения определяет версию установленного клиента. База знаний может обновляться независимо и должна отображать свою актуальность и версию внутри GovPro AI.

## Поддерживаемые платформы

Поддерживаемые платформы и архитектуры указываются непосредственно в каждом релизе. Не устанавливайте артефакт, если его платформа или архитектура не соответствует вашему устройству.
