# Метаданные обновлений GovPro AI

Клиент GovPro AI не должен разбирать HTML GitHub Releases для проверки обновлений. Для автоматического Update Center используется отдельный машиночитаемый источник метаданных.

Минимальная модель записи релиза:

| Поле | Назначение |
|---|---|
| version | версия приложения |
| channel | stable или beta |
| published_at | время публикации |
| release_url | официальная страница релиза |
| notes_url | заметки к релизу |
| source_ref | исходная ветка/тег/commit для сборки |
| source_commit | точный commit инженерного репозитория |
| platforms | доступные платформы и архитектуры |
| sha256 | контрольные суммы артефактов |
| signature | сведения о подписи |
| knowledge_base | версия и актуальность базы знаний |

## Принципы

1. Метаданные должны быть подписываемыми или доставляться по доверенному защищённому каналу.
2. Клиент проверяет совместимость платформы и архитектуры до загрузки.
3. SHA-256 проверяется после загрузки.
4. Цифровая подпись проверяется до установки.
5. Обновление устанавливается атомарно.
6. При неудаче обновления должен существовать безопасный путь отката.
7. Приватные ключи подписи никогда не хранятся в публичном репозитории.

GitHub Releases остаются официальной пользовательской страницей публикации, но не являются контрактом для парсинга HTML со стороны приложения.
