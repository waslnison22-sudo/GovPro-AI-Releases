# Публикация релиза GovPro AI

Официальная публикация выполняется из этого репозитория. Исходный код приложения остаётся в закрытом инженерном репозитории.

## Что требуется настроить один раз

В публичном репозитории добавляется GitHub Actions secret:

**SOURCE_REPO_TOKEN**

Токен должен позволять GitHub Actions этого репозитория читать приватный репозиторий:

waslnison22-sudo/Hellsaiz-Gov-AI

Токен не помещается в код, README, workflow или release assets.

## Подготовка версии

Перед публикацией создаётся файл:

release-notes/vX.Y.Z.md

Он должен содержать готовые русские release notes в формате проекта.

## Запуск

GitHub → Actions → **Publish GovPro AI release** → Run workflow.

Заполняются:

- версия, например 0.1.0;
- source ref инженерного репозитория;
- канал stable или beta.

Workflow:

1. получает исходный код;
2. выставляет единую версию приложения;
3. генерирует production-иконки;
4. собирает frontend;
5. параллельно собирает Windows x64, macOS Intel, macOS Apple Silicon и Linux x64;
6. проверяет, что все платформы собраны из одного engineering commit;
7. создаёт единый GitHub Release;
8. считает SHA-256 для всех установочных файлов;
9. публикует SHA256SUMS.txt и RELEASE_METADATA.json;
10. проверяет опубликованные assets;
11. обновляет машинно-читаемый channel JSON только после успешной публикации.

Отдельный metadata-gate проверяет структуру stable.json и beta.json при каждом изменении репозитория.

## Контроль перед публикацией

Перед запуском workflow следует свериться с docs/PRODUCTION_GATE_RU.md.

Каналы stable и beta не обновляются вручную: их JSON является машинным контрактом Update Center.

## Почему сейчас нет автоматической подписи

Updater-подпись Tauri требует отдельного приватного ключа. Tauri требует сохранять приватный ключ в секрете и использовать публичный ключ в конфигурации клиента. До создания постоянного ключевого контура workflow намеренно не публикует фиктивные подписи.

Это позволяет сначала получить воспроизводимый production build, а затем без подмены безопасности добавить подписанный updater.
