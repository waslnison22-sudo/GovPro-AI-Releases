# Подписание обновлений GovPro AI

Подпись обновлений включается отдельным этапом после проверки первого production build.

## Ключевая модель

Для Tauri updater используется пара ключей:

- публичный ключ — хранится в конфигурации приложения и может публиковаться;
- приватный ключ — хранится только как защищённый GitHub Actions secret.

Приватный ключ нельзя помещать в Git, README, release assets, исходный код или публичный репозиторий.

## Генерация

Ключевая пара создаётся локально через Tauri CLI:

`npm run tauri signer generate -- -w ~/.tauri/govpro-ai.key`

Приватный ключ и пароль от него сохраняются в безопасном хранилище владельца проекта.

## GitHub Actions

После этого приватный ключ передаётся workflow через secrets:

- `TAURI_SIGNING_PRIVATE_KEY`
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`

Публичный ключ добавляется в конфигурацию desktop-клиента.

## Проверка

Перед включением автоматического updater необходимо проверить:

1. подпись создаётся на каждом release artifact;
2. клиент принимает только корректную подпись;
3. изменённый после публикации artifact отклоняется;
4. неправильный публичный ключ отклоняет обновление;
5. обновление с несовместимой платформой не устанавливается;
6. неудачная установка не оставляет приложение в повреждённом состоянии.

До прохождения этих проверок workflow оставляет `signature_status: not_configured` и не создаёт видимость активного подписанного updater.
