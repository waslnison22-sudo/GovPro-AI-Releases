# GovPro AI v0.1.0-beta.1

**Канал:** Beta  
**Статус:** предварительный публичный кандидат  
**Дата публикации:** будет установлена GitHub Release при фактической публикации

## Новое

- Публичная регистрация и вход в GovPro AI через Supabase Auth.
- Работа с Server Profile и опубликованной Knowledge Base.
- Ассистент с ролями БАЗА, ОФИЦЕР, КРАЙМ, АДВОКАТ и ПРОКУРОР.
- Структурированные ответы с источниками, grounding и оценкой уверенности.
- Workspace для дел с событиями, доказательствами и анализом.
- Просмотр опубликованной базы правил и версий источников.
- Прикрепление изображений документов к запросу.
- Публичная release-инфраструктура для Windows, macOS и Linux.
- Контрольные суммы SHA-256 для опубликованных установочных файлов.

## Улучшено

- Компактный desktop-интерфейс GovPro AI.
- Разделение данных пользователя, Tenant и Server Profile.
- Детализирована модель provenance источников.
- Безопасное хранение desktop-сессии в системном credential store.
- Улучшена локализация API-ошибок.
- Добавлены readiness-проверки базы данных и GovPro Model runtime.

## Исправлено

- Сессия не сохраняется в обычных настройках или localStorage.
- Исправлена логика восстановления повреждённой сохранённой сессии.
- Ограничены размеры и количество изображений.
- Укреплена tenant/profile изоляция на уровне PostgreSQL.
- Усилена неизменяемость опубликованных версий Knowledge Base.
- Добавлена дополнительная защита от повторяющихся и некорректных model sections.

## Безопасность

- Добавлены RLS policies для Knowledge, Cases, Licensing и Audit.
- Добавлены cross-scope foreign keys для защиты от cross-tenant ссылок.
- Добавлен базовый per-user/per-tenant rate limit для дорогих API-операций.
- Добавлены privacy-safe audit events.
- Автоматический Stable release пока заблокирован до подключения подписи desktop updater.

## Известные ограничения

- Это Beta-версия.
- Production Supabase-проект и production GovPro Model runtime должны быть подключены отдельно.
- Native PDF/Word/OCR pipeline ещё не входит в этот кандидат.
- Signed automatic updater ещё не активирован.
- Полный held-out evaluation ещё должен быть выполнен на реальном наборе данных.

## Установка

### Windows

Скачайте официальный .exe или .msi из Assets опубликованного релиза.

### macOS

Скачайте .dmg для своей архитектуры.

### Linux

Скачайте .AppImage или .deb для x64.

## Контрольные суммы

SHA-256 публикуется в SHA256SUMS.txt внутри конкретного GitHub Release.

## Подпись

- Статус: not_configured для текущего Beta pipeline.
- Автоматический Stable updater не считается включённым до настройки signing key.

## База знаний

Версия Knowledge Base зависит от выбранного Server Profile и указывается внутри приложения.

## Обратная совместимость
